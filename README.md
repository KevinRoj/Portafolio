### ☕ [API REST de Gestión Deportiva](https://github.com/KevinRoj/gestion-deportiva)
Backend robusto y escalable desarrollado para la persistencia, consulta y administración eficiente de datos. El proyecto demuestra el dominio de la lógica del lado del servidor y estándares de desarrollo empresarial.

- **Tecnologías clave:** Java, Spring Boot, Hibernate, Spring Data JPA y H2 Database.
- **Logros técnicos:**
  - Diseño e implementación de una **arquitectura estructurada en capas** (`Model`, `Repository`, `Service`, `Controller`) garantizando la separación de responsabilidades.
  - Aplicación de mapeo objeto-relacional (ORM) mediante **Hibernate** para automatizar la interacción y conectividad con la base de datos de forma segura.
  - Creación de endpoints HTTP para operaciones CRUD estructurados estrictamente en formato **JSON** listos para consumo Frontend.
  - Configuración de un entorno de persistencia ágil *In-Memory* con H2 para optimización de pruebas locales.

👉 [Ver el repositorio del Backend aquí](https://github.com/KevinRoj/gestion-deportiva)

### 🐍 [Motor de Búsqueda y Ranking Algorítmico](https://github.com/KevinRoj)
Motor de búsqueda y ordenamiento en memoria desarrollado en **Python puro** sin dependencias externas, enfocado en estructuras de datos eficientes, filtrado multi-criterio y medición de rendimiento.

- **Tecnologías clave:** Python 3 (librería estándar: `collections`, `re`, `heapq`, `random`, `time`, `logging`).
- **Logros técnicos:**
  - Diseño modular en paquete (`engine/`) separando indexación (`indexer.py`), consultas y ranking (`query.py`) y pruebas de rendimiento (`benchmark.py`).
  - Construcción de un índice invertido (`dict` y `set`) con normalización de texto para recuperar candidatos por etiquetas, título y categoría.
  - Cálculo de relevancia y selección *Top-K* mediante `heapq.nlargest` con criterios de desempate deterministas por precio e identificador.
  - *Benchmark* reproducible con 20,000+ registros en memoria, logrando indexación sub-segundo y tiempos de consulta en el rango de milisegundos.

👉 [Ver el repositorio de Motor de Búsqueda y Ranking Algorítmico]((https://github.com/KevinRoj/algorithmic-search-engine))
